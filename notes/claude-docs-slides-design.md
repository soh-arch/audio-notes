# Claude Docs・Slides・Designとは何か

### この原稿で扱う範囲

この原稿では、アンソロピックが提供するクロードの3つの制作機能、すなわちクロードドックス、クロードスライド、クロードデザインを扱います。扱う順序は4つです。第1に、2026年9月16日の発表で何が変わったのか。第2に、3つの機能それぞれが具体的に何をするのか。第3に、どのプランでいつ使えるのか。第4に、公式に認められている制約と、まだ確かめられていない点です。

### 2026年9月16日の発表で何が変わったか

アンソロピックは2026年9月16日、クロードの画面構成を大きく作り変えると発表しました。具体的には、これまで独立した画面だったクロードコワークを、通常の会話画面に統合します。クロードコワークは、時間のかかる複数手順の作業をクロードに任せるための画面でした。同時に、クロードドックスとクロードスライドという2つの制作機能がベータ版として公開され、すでに存在していたクロードデザインも通常の会話の中から使えるようになりました。

この統合の理由について、アンソロピックは利用者からの声を挙げています。同社の説明によれば、人々は会話画面とクロードコワークの両方を使っていて、面倒なのは、その作業をどちらでやるべきかを決めることだ、という指摘があったとのことです。したがって、新しい設計では、利用者が事前に画面を選ぶ必要がなくなります。利用者は何をしたいかを説明するだけで、クロードの側が、それが短い返答で済むのか、調査が必要なのか、文書や資料の作成なのか、あるいは長時間動き続ける自律的な作業なのかを判断します。

### クロードドックスとは何か

クロードドックスは、クロードとの会話の中から共同編集できる文書を作る機能です。利用者が会話の流れで文書を頼むと、クロードが本文を書き起こします。重要な点は、できあがった文書がクロードの中で編集可能なまま残ることです。つまり、別のワープロソフトに貼り付け直す必要がありません。

クロードドックスはウェブに根ざした作り方をしています。具体的には、それぞれの文書が共有リンクを持ち、グーグルドキュメントのように扱えます。最初はすべての文書が非公開で、作成者が特定の相手や組織に共有できます。共有された相手は同時に編集でき、グーグルドキュメントに似た形でコメントを残せます。クロード自身も書き手として節ごとに下書きし、質問を投げ、選択について意見を書き込みます。

書き出しの形式は、発表時点でマイクロソフトのワードとグーグルドキュメントの2つです。アンソロピックは、書き出し形式を今後追加する予定だと述べています。

### クロードスライドとは何か

クロードスライドは、同じ考え方をプレゼンテーション資料に当てはめた機能です。利用者は通常の会話の中で資料一式を頼めます。できあがった資料は、スライド1枚単位で編集できます。さらに、クロードの画面からそのまま発表することもできます。

書き出しについては、パワーポイント形式かピーディーエフ形式でダウンロードできます。ここで区別しておくべき点があります。クロードスライドは、すでに存在するマイクロソフト365向けのパワーポイント用の拡張機能とは別物です。パワーポイントやエクセルに組み込む拡張機能は、今回の統合の対象外として、これまで通り別に提供され続けます。

### クロードデザインとは何か

クロードデザインは、3つの中で最も早く登場した機能です。アンソロピックの実験部門であるアンソロピックラボの製品として、2026年4月にリサーチプレビュー、つまり研究段階の先行公開という形で始まりました。公式のリリースノートでは4月16日、発表記事では4月17日と、日付の記載に1日のずれがあります。発表時点では、オーパス 4.7という画像を扱えるモデルで動いていると説明されていました。

クロードデザインが作るのは、デザイン案、動く試作品、スライド、1枚もののビジュアル資料などです。作り方は会話が起点になります。利用者が欲しいものを言葉で説明すると、クロードがキャンバス上に最初の案を描きます。そこからの調整手段は3通りあります。第1に、会話で指示すること。第2に、対象に直接コメントを書き込むこと。第3に、要素をつかんで動かす、大きさを変える、位置をそろえるといった、画面上での直接編集です。

クロードデザインの特徴として、デザインシステムへの対応があります。デザインシステムとは、組織のブランドの色、書体、部品の型をまとめた決まりごとのことです。組織があらかじめデザインシステムを登録しておくと、新しく作るものに自動で適用されます。チームとエンタープライズの管理者は、承認したデザインシステムを固定して、ブランドの統一を強制することもできます。

取り込みと書き出しの幅も広く取られています。取り込めるのは、スクリーンショット、コードの置き場所、デザインファイル、そしてワード形式、パワーポイント形式、エクセル形式の文書です。ウェブ上の見た目を取り込む機能もあります。書き出しは、圧縮ファイル、ピーディーエフ、パワーポイント形式、エイチティーエムエルのほか、キャンバ、フィグマ、アドビ、バーセルといった外部のツールへの引き渡しに対応しています。加えて、開発者向けのクロードコードへ作業を引き継ぐための一式も用意されています。

### 会話の中で何ができるようになるか

統合後の会話画面では、調査、報告書、表計算、プレゼンテーション資料といった重い作業を、通常の会話の中で頼めます。受け取るのは、後から編集できる完成ファイルです。具体的には、文書、計算式の入った表計算ファイル、パワーポイントの資料などです。

実行の仕方にも変更があります。手間のかかる作業は、利用者がノートパソコンを閉じたり画面を離れたりしても、クラウド側で動き続けます。そのため、進み具合を携帯電話から確認できます。作業中は、接続済みの外部サービスを使えます。接続先として挙げられているのは、グーグルドライブ、ジーメール、マイクロソフト365、スラックなどです。さらに、決まった時間に繰り返し実行する予約もできます。

なお、開発者向けのクロードコードは、これまで通り別の製品として残ります。また、統合前にクロードコワークで作った作業内容は引き継がれます。アンソロピックによれば、タスク、プロジェクト、接続設定、スキル、ファイルはそのまま新しい画面に移ります。

### 提供範囲とロールアウトの順序

2026年9月の統合は、段階的に配られます。最初に受け取るのは、プロとマックスの有料プランの利用者です。対象はウェブ、デスクトップ、携帯電話の3つで、数週間かけて順に広がります。チームとフリーのプランは、その後に続く予定とされています。エンタープライズ、つまり大企業向けの契約については、管理者に対して、組織で何かが変わる少なくとも30日前に連絡があると案内されています。

3つの制作機能のうち、クロードデザインの提供条件は個別に細かく決まっています。フリープランでは使えません。プロとマックスでは初めから有効で、設定から無効にできます。チームでも初めから有効です。エンタープライズでは初めは無効で、組織の所有者が組織設定から有効にする必要があります。管理者向けには、デザイン管理者という専用の権限があり、デザインシステムの承認と固定、成果物の公開範囲や外部共有の管理、使えるモデルの制御ができます。

使用量の扱いも押さえておく価値があります。クロードデザインには専用の使用枠がありません。クロードの他の機能と同じ上限を共有し、その枠はクロードコードとも共通です。

### 公式に認められている制約

アンソロピック自身のサポート文書は、クロードデザインについて複数の制約を挙げています。制約は5つです。第1に、コメントが消えずに残り続けるかどうかに問題があること。第2に、バージョン履歴、つまり過去の版に戻る仕組みがないこと。第3に、複数人が同時に編集する動作が安定しないこと。第4に、できあがるデザインの質が、取り込んだコードやファイルの質に左右されること。第5に、編集がウェブとデスクトップに限られ、携帯電話では編集できないことです。

クロードドックスとクロードスライドについては、公開されているのはベータ版です。したがって、機能も動作も今後変わる可能性があります。

### 効果の主張と、その確かさ

クロードデザインの発表時には、導入企業からの数値が紹介されました。学習サービスのブリリアントは、複雑なページを作り直す作業が、20を超えるプロンプトから2つのプロンプトに減ったと報告しています。プロンプトとは、クロードへの指示文のことです。また、監視サービスのデータドッグは、通常1週間かかっていた工程が1回の会話で済むようになったと述べています。

ここで注意が必要です。これらはいずれも導入企業側の申告であり、独立した第三者による検証ではありません。したがって、他の組織で同じ短縮が起きるとは限りません。

### 位置づけと、まだ分からないこと

今回の動きは、アンソロピックが対話型のクロードだけでなく、文書や資料そのものを扱う領域に踏み込んだことを意味します。競合として比較されるのは、グーグルワークスペースのジェミニと、マイクロソフト365のコパイロットです。ただし、成り立ちには違いがあります。ジェミニとコパイロットは、既存のオフィスソフトの中に組み込まれる形を取ります。これに対してクロードドックスとクロードスライドは、共有リンクの上に成果物が置かれるウェブ中心の作りで、そこから外部形式へ書き出す形を取ります。

最後に、現時点で確かでない点を整理します。3つあります。第1に、ベータ版であるため、機能の範囲も名称も変わりうること。第2に、段階的な配布のため、ある利用者の画面に表示されていないことが、機能が存在しないことを意味しないこと。第3に、統合後の自動的な振り分け、つまりクロードが自分でどう処理するかを判断する仕組みが、実際の業務でどれだけ正確に働くかについて、公開された評価結果がまだ見当たらないことです。以上の内容は、いずれも2026年9月16日の発表とその時点で公開されていた資料に基づいています。
